# Floor map assets

Đặt các file mặt bằng thật ở đây, ví dụ `floor1.svg`, `floor2.svg`.

Phiên bản hiện tại dựng SVG T1 trực tiếp trong `js/airport-map.js` để hiệu chỉnh và xoay khớp với footprint trên bản đồ nền. Khi có SVG chính thức, thay nội dung của `floorOneMarkup()` hoặc tải file tại `loadFloor()`.
